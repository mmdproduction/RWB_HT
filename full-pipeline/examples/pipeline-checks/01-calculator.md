Создай простой калькулятор с интерфейсом на русском языке.

На одном адаптивном экране размести два числовых поля, выбор операции (сложение, вычитание, умножение, деление), кнопку «Вычислить», крупный результат и кнопку «Сбросить». Поддерживаются отрицательные и дробные числа. Enter запускает вычисление. Сброс очищает поля, результат и ошибки.

Вычисление выполняется API приложения, интерфейс показывает полученный ответ. Пока запрос выполняется, повторная отправка недоступна. При сетевой ошибке покажи сообщение и разреши повторить запрос. Пустое поле, неверное число и деление на ноль должны давать понятную ошибку без успешного результата. После ошибки пользователь может исправить данные и вычислить заново.

Проверочные примеры: 2 + 3 = 5; -7 - 5 = -12; 1.5 × 4 = 6; 7 ÷ 2 = 3.5. Деление 5 на 0 запрещено.

Вход, роли, история вычислений, сохранение результатов, таблицы записей и аналитика не нужны. Основной экран должен сразу открывать калькулятор и быть удобным при ширине 360 пикселей.
