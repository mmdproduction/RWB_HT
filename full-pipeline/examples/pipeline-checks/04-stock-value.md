Создай PWA «Остатки склада» с ролями admin и user. Допустим демо-вход с выбором роли.

Сущность Product содержит name (обязательная строка), quantity (обязательное целое число) и unitPrice (обязательное число). Администратор создает, редактирует и удаляет товары. Пользователь user просматривает список и итоговую стоимость; API запрещает ему изменять товары.

Количество и цена не могут быть отрицательными. Нулевые количество и цена допустимы. Цена указывается в рублях, максимум два знака после запятой; более точную цену нужно отклонять с понятной ошибкой. Валидация выполняется и на сервере. Для денежных вычислений используй десятичную арифметику.

Главный экран содержит список товаров, количество, цену и стоимость каждой позиции. Стоимость позиции равна quantity × unitPrice. Над списком покажи общую стоимость всех товаров, вычисленную API из сохраненных записей. Денежные значения показываются с двумя знаками после запятой. После изменения и удаления товара итог обновляется. Для пустого склада итог равен 0.00 рубля.

Пример приемки в пустой базе: «Кабель», quantity=3, unitPrice=120.50 и «Адаптер», quantity=2, unitPrice=250.00. Стоимости позиций: 361.50 и 500.00, общий итог 861.50. Изменить количество кабелей на 4 — итог 982.00. Удалить адаптеры — итог 482.00. Дополнительная проверка: quantity=3 и unitPrice=0.10 дают стоимость 0.30.

Данные сохраняются после обновления страницы и перезапуска приложения. Интерфейс на русском, удобен на телефоне. Поставки, списания, бронирование, импорт, оплата и внешние интеграции не нужны.
