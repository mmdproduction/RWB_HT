Создай PWA «Задачи команды» с ролями admin и user. Демо-вход с выбором роли допустим.

Сущность Task содержит поля title (обязательная строка), priority (обязательное целое число), completed (boolean). Администратор создает, просматривает, редактирует и удаляет задачи. Пользователь user может просматривать задачи и сводку. Изменять записи пользователь user не может; запрет должен действовать и при прямом обращении к API.

На экране списка покажи название, приоритет и признак выполнения. Администратору доступны форма создания, редактирование и удаление с подтверждением. Перед вводом данных показывай понятное пустое состояние. Успешное изменение сразу отражается в списке. При ошибке сохранения введенные значения остаются в форме.

На отдельном экране сводки покажи количество всех, завершенных и открытых задач. Сводка вычисляется из актуальных сохраненных записей через API; число открытых равно общему количеству минус завершенные. После создания, изменения и удаления данные сводки обновляются при ее открытии.

Пример приемки в пустой базе: создать «Подготовить демо», priority=1, completed=false и «Проверить API», priority=2, completed=true. Сводка: всего 2, завершено 1, открыто 1. После завершения первой задачи: 2, 2, 0. После удаления второй: 1, 1, 0.

API отклоняет создание без title или priority, дробный priority и строку вместо boolean. Изменения сохраняются после обновления страницы и перезапуска приложения. Подписи на русском, адаптивная верстка. Внешние интеграции не нужны.
