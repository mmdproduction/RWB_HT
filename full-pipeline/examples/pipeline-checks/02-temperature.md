Создай конвертер температуры с интерфейсом на русском языке.

Один экран: числовое поле температуры, выбор направления «Цельсий → Фаренгейт» или «Фаренгейт → Цельсий», кнопка «Перевести», результат с единицей измерения и кнопка сброса. Поддерживаются отрицательные и дробные числа. Вход и история не нужны.

Преобразование выполняет API приложения. Формулы: F = C × 9 / 5 + 32; C = (F - 32) × 5 / 9. В интерфейсе результат округляется до двух знаков после запятой, допустимо скрывать конечные нули. Округление результата не должно менять исходное поле.

Проверочные примеры: 0 °C = 32 °F; 100 °C = 212 °F; -40 °C = -40 °F; 98.6 °F = 37 °C. Минимальная допустимая температура — -273.15 °C или -459.67 °F соответственно; это значение разрешено, более низкое запрещено.

Пустое поле и нечисловой ввод дают ошибку рядом с полем. Пока идет запрос, повторная отправка недоступна. При сетевой ошибке видна понятная подсказка и доступна повторная попытка. Сброс очищает ввод, результат и ошибку. Экран должен быть удобен на телефоне и с клавиатуры.

Сохранение записей, административная панель, аналитика и внешние интеграции не нужны.
