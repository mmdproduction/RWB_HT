Сделай простой калькулятор для обычного пользователя.

Один адаптивный экран: два числа, выбор сложения/вычитания/умножения/деления, заметная кнопка вычисления, крупный результат и сброс. Enter запускает вычисление. При пустом или неверном вводе покажи понятную ошибку рядом с полем; при делении на ноль — понятное сообщение. Во время запроса показывай состояние вычисления и не отправляй повторно. Вычисление выполняет API приложения, интерфейс показывает настоящий ответ.

Вход и роли, история, сводки, управление сущностями, административная панель и аналитика не нужны. На телефоне элементы должны оставаться удобными для нажатия. Подписи на русском. Интерфейс должен выглядеть как законченный калькулятор, с аккуратными полями, отступами и ясным главным действием.
