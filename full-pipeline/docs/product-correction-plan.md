# Исправление соответствия продукту и просмотра исходников

Основание: замечания пользователя о несоответствии ТЗ, низком качестве генерируемого frontend, отсутствии полного списка файлов и неверной формулировке бизнес-задачи. Уточнение пользователя: приоритет — **генерируемое приложение**.

Действующий стек и вариант A сохраняются. Выбор исполнителя: предметный интерфейс становится главным экраном; CRUD/workspace применяется только к задачам реестра/администрирования. Простому инструменту не добавляются искусственные сущности, история, роли и сводки. Исходный пользовательский запрос передается непосредственно генерации и исправлению. AppSpec явно описывает цель, главное действие, экраны, исключенный объем и необходимость входа.

Файлы запуска перечисляются по фактическому каталогу, включая незарегистрированные исходники, отчеты, конфигурацию и частичный результат. Панель получает дерево/поиск, просмотр текста и загрузку файлов. Секретные файлы обозначены, содержимое не публикуется. ZIP содержит все доступные материалы. Это исправляет существующую выдачу только зарегистрированных отчетов и архива.

План:

- [x] API полного списка файлов, текстового просмотра и скачивания; границы путей/секретов; ZIP всех публичных материалов.
- [x] AppSpec и промпты: цель/действия/экраны, отсутствие обязательных сущностей, исходный запрос как источник истины.
- [x] Генерируемый frontend: предметный главный экран, адаптивная оболочка, минимальный вход согласно задаче; реальные бизнес-действия без технических меню по умолчанию.
- [x] Панель: просмотр файлов и исходной/сформированной задачи в рабочем пространстве запуска.
- [x] Применить изменения к контейнерам; дополнительные тесты/генерации не запускались по прежнему указанию пользователя. Панель собрана; контейнеры API, worker и frontend пересобраны/перезапущены. Полная новая генерация и визуальная приемка остаются непроверенными.

Старые завершенные результаты сохраняются как история; новые правила генерации действуют для новых запусков. Просмотр файлов работает и для существующих запусков.
