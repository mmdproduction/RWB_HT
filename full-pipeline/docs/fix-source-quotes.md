# sourceQuote: переносы исходного текста

Ошибка возникала на анализе: код проверял `sourceQuote in original_request` и делал любое несовпадение фатальной ошибкой. Исходный запрос парковочного кейса содержит PDF-переносы строк. Ответ неудачной попытки ранее не сохранялся, поэтому точное отличие конкретной цитаты модели восстановить из прежних артефактов нельзя.

Локальное исправление действующего пайплайна, без изменения архитектуры:

- Проверка допускает различия только в Unicode-пробелах/переносах и канонической NFC-форме. Регистр и слова не подменяются.
- При совпадении сохраняется точная подстрока оригинала, вместе с ее смещениями в отчете.
- Не найденная цитата очищается и отмечается `unverified` в `reports/source-quote-audit.json`. Это не подтверждение корректности самого требования.
- Исходный пользовательский текст не меняется. Ответы анализа теперь сохраняются по попыткам для диагностики.
- Проверки бизнес-требований, критических вопросов, сборки и приемки остаются действующими.

Новых тестов/генераций не запускалось по указанию пользователя. Для применения к завершенному неудачному кейсу нужен новый запуск; история старого результата сохраняется.
