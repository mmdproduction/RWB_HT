# Генерируемый интерфейс: исправление фокуса продукта

Изменена только оболочка генерируемого приложения (`templates/assets/frontend`), не интерфейс платформы.

- `GeneratedPanel` теперь самостоятельный главный экран «Приложение». Он больше не вставляется под универсальную таблицу.
- `uiMode: focused` не выводит разделы сущностей и CRUD. Оболочка показывает название, бизнес-цель и предметный экран без технического брендинга и искусственных сводок.
- При `requiresLogin: false` нет формы входа и переключателя ролей. Для совместимости с защищенными API оболочка получает транспортный демонстрационный токен роли `user` либо первой неадминистративной роли; для парковки — `driver`. Скрытый вход никогда не запрашивает `admin`.
- Старые спецификации сохраняют workspace и явный демонстрационный вход. Реестры доступны отдельным разделом при наличии сущностей. Пустой массив сущностей безопасен.
- Парковочное приложение сразу открывает экран водителя. Существующие API, сценарии сессии, схема зон и расчет границ карты сохранены. Предметный генерируемый экран доступен отдельным разделом.
- Обновлены адаптивная типографика, карточки, поля, отступы, навигация, мобильная верстка, состояния загрузки/ошибки/пустого результата и восстановление соединения. Повтор ошибки обновляет состояние без автоматического повторения записи.
- Добавлены общие `--product-*` и `--color-*` переменные, классы `.product-card`, `.product-grid`, `.product-field`, `.product-action`, `.product-result`, `.product-error` и дополнительные композиционные утилиты. Бизнес-логика конкретного нового инструмента в оболочку не зашита.
- Статический запасной `GeneratedPanel` честно сообщает об отсутствии подготовленного экрана. Заголовок страницы обновляется по спецификации, запасные заголовки/манифест не рекламируют стек.

## Подготовка и ограничения проверки

Строгая компиляция TypeScript и Angular-шаблонов измененного AppComponent и его GeneratedPanel завершилась успешно через установленный Angular compiler 20.1.6. Полная production-сборка шаблона была запущена, но заблокирована отсутствующим в имеющихся локальных зависимостях пакетом `@angular/service-worker`; его архив отсутствует и в локальном npm-кэше. Дополнительные загрузки или установка зависимостей не выполнялись, lock-файл не изменен. Временные конфигурация компиляции, ссылка на зависимости и build-кэш удалены.

По указанию пользователя дополнительные тесты, генерации Qwen, запуск приложения, браузерная проверка и Docker-проверки не проводились. Внешний вид нового предметного экрана зависит от результата последующей генерации; настоящая новая генерация этой правкой не выполнялась.

После независимого чтения кода добавлен product-api.ts: общий same-origin transport получает актуальный токен из sessionStorage и один раз обновляет публичный token при401; обычные действия публичного инструмента не требуют admin. При открытии публичного приложения токен обновляется. Генератору передан этот контракт, исходная бизнес-задача и продуктовые CSS-переменные. Первичная генерация, не содержащая обоих entrypoint исходников, теперь отклоняется. Эти последние изменения повторно не компилировались/не тестировались по указанию пользователя; они включены в образ worker.
