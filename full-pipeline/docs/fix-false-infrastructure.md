# Ложная блокировка успешной сборки

В запуске `bd236830-7fe9-46ec-a782-2c43f297e2a3` файл `reports/01-build.json` содержит `returnCode: 0`. Все образы успешно собраны. Инфраструктурного сбоя в предоставленном журнале нет.

## Причина

Предыдущее изменение классификатора сетевых сбоев искало `502`, `503` или `504` в произвольном месте строки с `docker.io`. Реальный SHA256 образа Python содержит `502` как часть хеша. Дополнительно обработчики обычной и кандидатной сборки вызывали проверку инфраструктурной ошибки до проверки успешного кода завершения. Вместе эти ошибки привели к ложному `blocked` после успешной сборки.

## Исправление

- Обычная и кандидатная сборки классифицируют ошибки только при ненулевом коде завершения. Успех команды не отменяется содержимым ее журнала.
- Проверка ошибок registry требует сообщения с кодом и названием HTTP-ошибки, например `503 Service Unavailable`; цифры внутри SHA256 не подходят.
- Существующие ограниченные повторы при настоящем `TLS handshake timeout` сохранены.

Добавлены регрессионные проверки для реального digest из журнала и для успешной команды, печатающей текст о сетевых ошибках. По указанию пользователя тесты и новые генерации не запускаются; выполнена только компиляция Python. Исторические артефакты и статусы завершенных запусков не изменены.
