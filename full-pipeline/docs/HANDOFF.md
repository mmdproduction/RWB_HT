## Что реализовано

- Angular/Material-панель: требования, история, стадии/логи, метрики, ссылки и скачивание артефактов.
- FastAPI + PostgreSQL: очередь, атомарное получение, idempotency для claim/progress, lease/heartbeat, остановка устаревшего задания, защищенные внутренние endpoints, архивы.
- Python worker: реальный Qwen, AppSpec, предметные исходники, реальные Docker-сборки/HTTP-проверки, максимум два исправления кода, npm/NuGet аудит, развертывание и документы.
- Генерируемый проект: Angular20.1.6/Material/PWA, C#14/.NET10, PostgreSQL17.9/PostGIS. Общий CRUD и парковочный сценарий, предметные расширения от модели.
- Docker Compose для платформы и результата, Dockerfiles, GitLab CI, примеры требований и инструкция README.

## Исправления по независимой проверке

- Проверка `/api/` на backend приведена к OrdinalIgnoreCase. Добавлена прямая проверка backend для смешанного регистра (через Nginx такой URL мог уйти в SPA fallback).
- Приемка использует отдельный временный Compose-проект/volume, финальный deployment — свежую БД без тестовых часов/токенов/фикстур; clock по умолчанию отключен при deployment.
- Очистка после сбоя вынесена в локальный finally без зависимости от API; потеря lease отменяет команды.
- Повтор claim использует стабильный requestId и возвращает прежнюю lease, не забирая следующее задание.
- В генерируемый CI добавлены предметные HTTP-проверки и проверка сохранности после перезапуска.

Последние изменения целого deployment/cleanup/CI не прошли повторную комплексную приемку: это сознательно оставлено пользователю по его указанию.

## Как запустить сейчас

SSH-туннель должен оставаться открытым. Локальный `.env` уже подготовлен; при переносе используйте `python3 scripts/setup_env.py` и задайте свой ключ.

```bash
cd '/home/evodev/Документы/ChatGPT/RWB хахатон/full-pipeline'
docker compose up -d --build --wait
```

Панель: http://127.0.0.1:8090. API: http://127.0.0.1:8100/docs. Для первого запуска вставьте `examples/tasks.md` либо `examples/parking.md`.

Временные локальные процессы API/worker остановлены, чтобы не занять порты перед Compose. БД нового пайплайна сохранена; исходная БД учебного проекта не затронута. Внешний GitLab не запускался. Инструкция проверки/остановки и ограничения находятся в README.
