# План реализации архитектуры v2

Основание: docs/agent-architecture-v2.md; прямое поручение пользователя исправить архитектуру. Изменения выполняются в существующей выделенной рабочей области, без Git-публикации.

- [ ] Типизированные Blueprint/AcceptancePlan/Review/RepairPlan и детерминированная проверка связей требований, ролей, endpoints и UI testId.
- [ ] Изолированные агентные задачи, протокол состояния/артефактов, разные права записи, метрики и зависимости.
- [ ] Независимая приемка до кода, раздельная backend/frontend реализация, независимое ревью и адресные исправления.
- [ ] Подключить фактические HTTP и desktop/mobile Chromium проверки, результаты/скриншоты; сохранить неподтвержденные ручные пункты.
- [ ] Заменить монолитную генерацию в Engine координатором; проверять актуальный hash кода перед выпуском, сохранять существующий API.
- [ ] Собрать/применить контейнеры, обновить документацию; дополнительных тестов и генераций не запускать по указанию пользователя.
