# Task 5: интерфейс платформы

План: docs/implementation-plan.md, задача 5. Основание: утвержденный вариант A, docs/design.md и публичный контракт platform_api.

Ruling: реализация ограничена frontend/** и этим отчетом; отдельный Git-worktree, Git-коммиты и вложенные исполнители не создаются по прямому назначению владельца интеграции. Задача выполняется в уже выделенном каталоге full-pipeline.

Проверки до реализации: `node --test frontend/tests/run-state.test.mjs` завершился ожидаемым MODULE_NOT_FOUND для еще не созданного run-state.ts. Поведенческие проверки охватывают active/terminal polling, безопасные внешние ссылки, долю пройденных стадий и монотонный курсор финальных логов; без дополнительного тестового фреймворка.

Реализованы русская Angular/Material-панель (20.1.6), создание/история, стадии/журнал, результат/файлы. URL `?run=` восстанавливает выбранный запуск; старые требования копируются в форму нового запуска. Статусы queued и running различаются; таймер 3 секунды работает только при активных запусках. Финальный журнал дочитывается до пустой страницы; на экране сохраняются последние 2000 событий. Устаревшие ответы выбранного запуска игнорируются. Секреты/внутренние endpoints не используются. Текст выводится через интерполяцию; app/repository ссылки допускают только HTTP(S); ссылки артефактов строятся из ID публичного API.

Nginx направляет /api/ в api:8000; /health проверяет контейнер панели. Dev proxy направляет /api в 127.0.0.1:8100. Dockerfile собирает на Node24 и отдает Nginx.

Фактические результаты:

- `npm install --no-audit --no-fund --fetch-retries=0 --fetch-timeout=20000` завершен успешно (459 пакетов); создан настоящий package-lock.json. Фиксированы Angular/Material 20.1.6 и TypeScript 5.8.3. Установка в sandbox была остановлена после отсутствия сетевого прогресса; загрузка завершена с разрешенным внешним доступом.
- `npm test`: 4 проверки пройдены, 0 ошибок. Выполнено до просьбы пользователя прекратить дополнительное тестирование.
- `npm run build`: успешная production-сборка. Initial bundle 493.76 kB, расчетный transfer 117.32 kB; вывод frontend/dist/console/browser. Первая компиляция выявила буквальные фигурные скобки в декоративном элементе Angular-шаблона; скобки экранированы HTML entities, запущенная сборка завершена успешно.
- npm сообщил об устаревших транзитивных tar 6.2.1 и glob 10.5.0, а также о четырех неподтвержденных install scripts. Это не помешало сборке; аудит зависимости не заявляется.

Ограничения: браузерное выполнение и ручная проверка на живом API не проводились. По последнему указанию пользователя новые тесты/браузерные проверки не запускать, пользователь проверит самостоятельно. Nginx/Docker контейнер панели отдельно в рамках задачи не запускался. Наличие настроенного ключа модели/исполнителя в /api/config отображается как конфигурация, а не гарантия сетевой доступности. Исходный исходящий API здесь не подменялся фиктивными данными.
