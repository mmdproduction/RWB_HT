# Единый стиль панели с сохранением функций

## Задача

Объединить оформление RWB_HT/front и исходные возможности панели пайплайна. Общая палитра: тёмно-синий фон, синие и голубые акценты, светлые рабочие карточки, тёмные области кода и журнала. Одинаковые размеры текста, кнопки, отступы и состояния на всех экранах.

Выбран единый набор стилей и сохранение существующих компонентов дерева и мониторинга. Альтернатива — оформление поверх отдельных старых стилей — оставила бы конфликты специфичности. Переписывание файлового API или генератора для задачи оформления не требуется.

## Сохраняемые возможности

| Возможность | Где доступна |
|---|---|
| Создание задачи до 100 000 символов | Главная страница |
| История, реальные статусы, время, автообновление, ручное обновление | Главная и страницы запуска |
| Готовность модели и исполнителя, статус и история Qwen | Общая область панели |
| Стадии, попытки, сообщения, прогресс, длительность, вызовы модели, повторы, токены | Процесс и результат |
| Журнал с курсором и повтор загрузки | Процесс |
| Открытие приложения и репозитория при наличии ссылки | Результат |
| Дерево всех доступных файлов, поиск по пути, свернуть/развернуть папки | Файлы |
| Просмотр кода с номерами строк, копирование, скачивание файла | Файлы |
| ZIP, видимость защищённых и неподдерживаемых файлов | Файлы и результат |
| Исходный запрос, анализ, спецификация, допущения | Бизнес-задача |
| Использовать требования повторно | Общая шапка запуска |
| Файлы и задача доступны до завершения и после ошибки | Вкладки запуска |
| Старые ссылки /?run=UUID | Перенаправление на процесс |

## Реализация 31.10.2026

- Общая тема находится в frontend/src/styles.scss. Отдельные встроенные стили страниц удалены; проводник и монитор Qwen используют те же цвета, шрифты, отступы и состояния.
- Общая шапка RunHeaderComponent даёт вкладки «Процесс выполнения», «Результат», «Файлы проекта», «Бизнес-задача» и действия обновления/повторного использования требований.
- Файлы доступны по /result/UUID?view=files, задача — /result/UUID?view=task. Между вкладками сохраняются выбранный файл, поиск и свёрнутые папки в рамках страницы результата. Проводник остаётся смонтированным при открытии сводки результата.
- Готовность среды снова видна через /api/config; сохранён отдельный монитор соединения Qwen. История имеет ручное обновление и время последней загрузки.
- Смена UUID отменяет предыдущие запросы и очищает данные прошлого запуска. После временной ошибки загрузки результата повтор возобновляется через 3 секунды; некорректные и неизвестные UUID не вызывают бесконечных повторов.
- TypeScript/HTML файлового проводника и мониторинга Qwen сохранены. Внешний вид их компонентов обновлён через CSS.
- Финальная Docker/Angular сборка завершилась успешно. Выполнено отдельное чтение кода на потерю возможностей; найденное прекращение автообновления после временной ошибки исправлено. Поведенческие и визуальные тесты не запускались.

Локальная панель: http://127.0.0.1:8090/new. Выбрать запуск в истории → «Файлы проекта» для дерева и просмотра кода. Обновление VM — отдельно по deploy-vm.md; на VM эти изменения не применялись.
